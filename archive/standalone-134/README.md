# Archived: standalone 134-mod pack

The first version of MinecraftModded: 134 mods for Minecraft 1.21.1 on NeoForge 21.1.259, imported from
`temp-modlist.txt` with the original file versions. All 134 downloads passed checksum verification. The game
itself was never launch-tested.

The pack now builds on Craftoria (see the main README). These files are kept for reference only. They are not
indexed or published, and `scripts/import_craftoria.py` reads `sources/resolved.json` from here to list the
archived mods that Craftoria does not include (candidates for extras).

To use the standalone pack again, check out commit `f6ce336`, the last commit before the move. It contains
the old importer and validator as well.
