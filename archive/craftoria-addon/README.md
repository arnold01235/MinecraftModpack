# Archived: Craftoria add-on (1.37.0-1)

The pack as it was before switching the base modpack to All the Mods 10: Aeronautics on 2026-10-20.
It was an add-on for Craftoria 1.37.0 (CurseForge project 1039252, file 8874369, NeoForge 21.1.249) with four
extras: Create Aeronautics 1.3.2, Sable 2.0.6, Distant Horizons 3.3.3 and Distant Horizons SeedGen 0.9.1.

These are copies of `pack.toml`, `index.toml`, `mods/` and `sources/` from commit b7ea8ad. They are not built or
served. To go back, restore `sources/pack.json` from here and rerun `scripts/import_craftoria.py` against a
Craftoria profile.
